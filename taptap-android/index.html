《诺亚基地》隐私政策

本政策适用于通过 TapTap 分发的中国大陆 Android 版《诺亚基地》，应用包名为 com.breakwater.fogwatch。

个人信息处理者为 Kevin工作室。本政策自公布之日起生效。隐私联系邮箱为 166820145@qq.com。

登录和实名防沉迷

游戏在进入战役前通过 TapTap 完成登录和实名防沉迷检查。您可以先查看本政策，选择「同意并验证」后，游戏才调用 TapSDK 的登录和合规服务。您也可以退出。适用的实名或游戏时长限制由合规服务返回，游戏据此决定是否允许进入或继续战役。

您首次登录或需要重新授权时，游戏会在设备上检查 TapTap 客户端能否打开授权页。这个检查用于选择登录方式，范围限于 TapTap 客户端。需要网页授权时，游戏会在您同意后启动 Android 系统 WebView，由 TapTap 显示登录表单。您可以关闭表单并返回验证页。

游戏接收 TapTap 的账号标识和合规状态，并将账号标识交给 TapTap 合规服务，用于完成本次资格检查。我们的游戏代码不提供身份证件上传功能，也不接收或保存您在 TapTap 认证界面提交的姓名、证件号码及证件照片。

第三方 SDK

游戏使用易玩（上海）网络科技有限公司提供的 TapSDK，包含核心、登录和合规模块。登录和合规功能会使用网络连接及网络状态，并可能处理系统信息、设备型号、CPU 和内存信息、网络类型及 Android ID。TapTap 认证服务对实名信息的处理、保存和用户权利，以其公开说明为准。TapSDK 隐私政策 · TapSDK 合规使用说明

本地战役存档

战役进度保存在设备应用数据目录，供您继续游戏。游戏不提供云存档和应用内购买。您可以通过系统设置清除应用数据，这会删除本机战役进度及本应用内的本地登录状态。清除本机数据不影响 TapTap 依其规则保存的账号和实名信息。

自愿观看的激励视频

支持广告的 Android 包可在黎明提供一次额外补给。您选择观看并确认后，游戏才初始化上海艾得蒽数字科技有限公司提供的 TapADN SDK 并请求广告。跳过、取消或加载失败可以继续游戏。未配置推广位的版本不提供该入口。

为完成广告展示、反作弊和奖励核对，SDK 会与广告平台通信；游戏传入一笔随机生成的奖励订单标识，并在本机保存待结算记录。游戏关闭 SDK 的位置、电话状态、Android ID、OAID、已安装应用列表、Wi-Fi 信息和传感器采集开关。具体数据处理及权利说明见 TapADN SDK 隐私政策。

未满十四周岁的玩家请由监护人阅读本政策，并由监护人按适用规则及 TapTap 提示处理授权。实名和游玩时间限制由 TapTap 合规服务执行。监护人可以通过下方联系方式咨询，也可以通过 TapTap 管理该平台处理的实名信息。TapSDK 隐私政策
